# Deferred scope (v2 and later)

Items deliberately left out of the current milestone. Solve the smallest version first; real use
decides which of these come back. Add the source (kickoff, spec NN, task Tn) and the reason.

| Item | Reason deferred | Source | Revisit when |
|---|---|---|---|
| Semantic search (local model or embeddings API) | Text search is fast and free at current volume | kickoff | Text search misses notes the owner knows exist, repeatedly |
| Other LLM providers | One provider first; the LLM interface keeps the door open | kickoff | A user asks for one, or Anthropic pricing changes the budget |
| Install without n8n | n8n holds credentials and approvals; replacing it is a large project | kickoff | Installs fail because users lack n8n |
| Several owners in one install | One owner per install keeps auth and config simple | kickoff | A team asks to share one server |
| Published container images (registry) | The server builds the image from the repository | kickoff | Builds on small hosts become too slow |
| Deploy from CI | Deploy is infra and tier C; manual deploy is one command | kickoff | Releases become frequent enough that manual deploy hurts |
| Meeting analysis in the pipeline | Runs in the owner's subscription through the analizar-reunion skill (docs/adr/0004-meetings-without-llm.md) | kickoff | The owner wants analyses without asking and accepts the API cost |
